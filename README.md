# 病理侦探：你能看见疾病吗？

双击 `index.html`，用 Edge、Chrome 或 Firefox 打开。无需安装、联网或启动服务器。点击右上角“全屏”（或 F11）用于课堂投影。请将 HTML、CSS、JS 和“images”文件夹保持原有相对位置。

## 玩法与课堂节奏

建议全程约 5 分钟：每关约 60—75 秒，包含观察与讨论，不设强制等待。

1. 肉眼观察：在历史解剖图上移动观察镜，找到并记录三个热点。热点只提示轮廓和层次，不代表病灶。
2. 显微镜与染色：圆形视野内移动观察，提高染色强度并记录左、中、右三个视区。画面为已染色图的视觉模拟。
3. 数字病理：抓住扫描线拖动覆盖整张切片，再点击数字界面的局部、坐标、分子标记三个区域。
4. AI 虚拟染色：按顺序接通输入、分析、预测、真实染色比较验证四个节点；顺序错误可重试。预测以概念占位显示，不生成医学结果。

顶部显示时代、16 条观察记录与 10%—100% 可见度（游戏进度，不是诊断指标）。完成操作后手动进入下一关。结尾动态展示六节点演化链及本次解锁记录。

鼠标、触屏与键盘均可操作：观察镜和显微视野使用方向键移动、Enter 记录；扫描线使用左右方向键。Esc 关闭原图或素材说明。系统“减少动态效果”偏好会被尊重。回访不会重复计分，重新探索会清空本轮进度。

- `virtual_staining(1).pptx`：提取全部 20 页的文本，采用输入—计算—预测及“形态不唯一决定蛋白表达”的说明。
- `images/`：39 张 JPG 均生成缩略图并检查。按下列可见内容核对，不因编号而推断疾病。

## 示意边界

没有额外下载或生成医学图片，没有虚构病例。低对比染色画面只是对现有已染色图片应用灰度、对比度和亮度变化，不是真实未染色图，也不模拟化学反应的物理过程。放大是屏幕缩放，无真实倍率或尺寸含义。

数字扫描与 AI 扫描只展示工作流程。AI 页面不运行模型，不生成医学图像，不提供诊断；特定蛋白表达须结合实际检测及适用范围验证。各阶段图片不是同一病例的连续检查。

原始资料没有被修改。辅助检查文件 `inspect_materials.py` 与 `inspection/` 留作核对记录，运行游戏不依赖它们。`verify_game.cjs` 是本机浏览器验证脚本，运行游戏也不需要它。
